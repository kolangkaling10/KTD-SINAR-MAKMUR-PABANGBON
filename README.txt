Untuk GitHub Pages:
1. Upload semua isi folder ini ke ROOT repository.
2. Jangan upload folder pembungkus KTH-SINAR-MAKMUR-GITHUB-FINAL-RESPONSIVE.
3. Pastikan `index.html`, `css`, `js`, dan `images` sejajar.
4. Settings > Pages > Deploy from a branch > main > / (root).
